mqtt-executor — API playground

HTTP ingress next to MQTT. OpenAPI spec. MQTT side effects (STATE/RESULT, sensor publishes) apply when a broker is configured.

POST /trigger/{name}

Starts the command and waits for its completion. The body is passed to the command as stdin when the trigger is configured with stdin_payload: true.

The background button calls POST /trigger/{name}/run and returns when accepted.






DELETE /trigger/{name}


Interrupts a running command (idempotent). Alias: POST /trigger/{name}/stop.



  
  
  





GET /sensor/{name}


Starts or joins a measurement and returns the output.
